# intent.md — LifeDNA 사전예약 랜딩페이지

## 무엇을 (What)
- **LifeDNA 사전예약 랜딩페이지**: 웰니스 앱 컨셉을 소개하고, 이메일로 사전예약을 신청받는 1페이지 웹사이트
- 이미 만들어둔 모바일 앱(목업 + TestFlight, 아직 정식 출시 전)을 홍보하기 위한 용도
- 사전예약 신청 방식: **이메일만 남기면 완료** (결제·카드 등록 없음)
- **개인정보처리방침 페이지도 함께 제작** (이메일을 수집하므로 정식 페이지 필요)

## 왜 (Why)
- 웰니스를 실천하려는 사람들이 여러 앱을 써봤지만,
  - 대부분 기능이 파편화되어 있음 (수면 앱 따로, 운동 앱 따로 …)
  - 통합 플랫폼이 있어도 대부분 웨어러블 디바이스가 있어야만 쓸 수 있음
- → **웨어러블 없이도 쓰는 통합 웰니스 플랫폼**이 실제로 사람들에게 매력적인지, **지불 의사가 있는지**를 사전예약 신청 수로 검증하고 싶음

## 대상 (Who)
- 일반 대중 (SNS 등으로 넓게 노출, 특정 커뮤니티 한정 아님)

## 성공 기준 (Success)
- **1개월 안에 사전예약(이메일) 100명** 달성 → 지불 의사가 있다고 판단
- 100명 미달 시: 문구·타겟·컨셉 재검토 필요

## 제약 (Constraints)
- 기술 스택은 프로젝트 규칙 고정: Next.js + TypeScript + Tailwind + Supabase(이메일 저장용) + Vercel 배포
- 사용자는 비개발자 — 코드는 Claude가 작성, 사용자는 기획/확인 담당
- 콘텐츠는 기존 컨셉 문서(`lifedna_overview_1.html`)를 기반으로 재구성

## 디자인 참고 자료 (Reference)
- `lifedna_home_3.html` — 실제 앱 프로토타입 목업 (폰 화면, 홈/기록/캘린더/개선책/구독/MY 등)
  - 파랑→보라 그라데이션, "살아있는 컨디션 오브" 비주얼이 브랜드 아이덴티티
  - 랜딩페이지의 톤앤매너·컬러·핵심 비주얼(오브)을 여기서 가져와 일관성 유지
  - 화면별 상세 기능은 `docs/spec.md`에서 다룸
